# Popup Announcement Folder Instructions

This folder controls the optional responsive announcement popup shown on page load.
The popup supports a modern **2-slide carousel** featuring a **video** (Slide 1) and an **image** (Slide 2), along with touch swipe gestures, sound control, and multilingual text.

---

## 1. Media Files (Activation Trigger)

The popup automatically activates when at least one media file is present in this folder.

### Slide 1: Video Player (Optional)
Place a video file named one of the following:
- `popup.mp4` / `video.mp4`
- `popup.webm` / `video.webm`

*Features:*
- Plays inline (`playsinline`).
- **Sound active by default (`muted = false`):** Attempts unmuted playback immediately on load and open. If browser autoplay restrictions temporarily intervene, audio instantly activates on the user's first click, tap, or interaction anywhere on the window.
- Dedicated sound toggle button (🔊 / 🔇) with accessible tooltips and ARIA states.
- Clicking the video toggles play / pause with a visual pulse indicator.
- **Auto-pauses** automatically whenever navigating away from the video slide or dismissing the popup.

### Slide 2: Static Image (Optional)
Place an image file named one of the following:
- `popup.jpg` / `popup.jpeg` / `popup.png` / `popup.webp`
- `image.jpg` / `image.jpeg` / `image.png` / `image.webp`

### Fallback Behavior:
- **Both files exist:** A 2-slide carousel is generated (Slide 1: Video, Slide 2: Image) with navigation arrows, indicator dots, and swipe gestures.
- **Only one file exists:** Gracefully renders in single-slide mode (indicators and arrows are hidden).
- **Neither file exists:** The popup is completely disabled and not rendered in the DOM.

---

## 2. Text & Multilingual Support (Markdown)

Place markdown files to provide localized text beneath the media:
- Persian: `popup.fa.md` (renders in **RTL** layout automatically)
- German: `popup.de.md`
- English: `popup.en.md`
- Default Fallback: `popup.md` or `text.md`

### Separating Slide 1 and Slide 2 Content
Use standard Markdown dividers (e.g. `---`, `***`, `___`) or slide tags (`<!-- slide -->`, `---slide---`) to separate the text for Slide 1 from Slide 2:

```markdown
### پاسداشت جشن مهرگان
جشن دوستی، فرهنگ و روشنایی. ویدیوی معرفی برنامه و گردهمایی بزرگ مهرگان را مشاهده کنید.

---

### جشن کهن مهرگان
- **زمان:** شنبه ۱۰ اکتبر ۲۰۲۶ | ساعت ۱۷:۰۰ الی ۲۱:۰۰
- **مکان:** Scherffenberggasse 5/1/R02, 1180 Wien
```

*Notes:*
- Supports `---`, `***`, `___`, `<!-- slide -->`, and `---slide---`.
- Fully resilient against Unicode direction marks (`\u200E`, `\u200F`), zero-width characters, and spacing variances often generated by Persian keyboards and RTL editors.
- If a delimiter is present, the first section attaches to Slide 1 and the second section attaches to Slide 2.
- If no delimiter is present, the same text applies to both slides.
- Standard Markdown formatting is supported: `#`, `##`, `###`, `**bold**`, `*italic*`, `[link](url)`, and bullet lists `-`.

### Contact Details Obfuscation (`b64:` Pattern)
To protect contact details from web scrapers and prevent plain-text exposure in the source code, phone numbers and email addresses use Base64 encoding with the project-wide `b64:` prefix:
```markdown
[b64:<base64-label>](b64:<base64-url>)
```

*Example:*
```markdown
- **هماهنگی و رزرو:** [b64:MDA0MyA2NzYgNzA1MTAwMg==](b64:dGVsOis0MzY3NjcwNTEwMDI=) | [b64:Y29udGFjdEBsaW9uYW5kc3VuY2VudGVyLm9yZw==](b64:bWFpbHRvOmNvbnRhY3RAbGlvbmFuZHN1bmNlbnRlci5vcmc=)
```

- **Encoding helper (terminal):**
  ```bash
  echo -n "tel:+436767051002" | base64
  echo -n "0043 676 7051002" | base64
  ```
- **Runtime Decryption:** The Markdown parser outputs safe HTML elements (`<a href="#" data-b64-href="..." data-b64-text="..."></a>`) that are decoded strictly client-side at the moment of display via `atob()` and injected directly into the live DOM with telephone / email micro-icons.

## 3. Gestures & Interactions
- **Touch & Swipe:** Users can swipe horizontally across **both** the media container and the text section to flip between slides.
- **Indicators:** Clickable dot indicators provide immediate navigation and visual state.
- **Arrows:** Left/Right chevron buttons are available for desktop and accessibility.
- **Dismissal:** Dismiss via the close button (✕), tapping the backdrop, or pressing the `Escape` key.
- **FAB Re-opening:** A floating announcement icon remains in the bottom-right corner to allow visitors to re-open the popup at any time.

---

## 4. How to Disable the Popup
To completely disable the popup manually at any time, simply remove or rename the media files (`.mp4`, `.webm`, `.jpg`, `.png`) in this folder.

---

## 5. Automatic Expiration Date
The popup includes an automatic event deadline logic in `js/popup.js`:
```javascript
const EXPIRATION_DATE = new Date("2026-10-11T23:59:59+02:00");
```
- **Mehregan Event Expiry:** The popup is visible up to and including **October 11, 2026 at 23:59:59 (Vienna time / CEST)**.
- Once this deadline passes, the client's script completely suppresses the popup: no modal, backdrop, or floating button will be rendered or opened, even if media or markdown files remain in this folder.
- **Future Announcements:** To set a new expiration deadline, update `EXPIRATION_DATE` in [`js/popup.js`](../js/popup.js) with the new ISO date string, or set it to `null` to leave the popup active indefinitely.

---

## 6. Aspect Ratio & Dynamic Layout Detection
The popup automatically detects whether your media is **Landscape (horizontal)** or **Portrait (vertical)**:
- **Landscape Media (16:9 / horizontal):**
  Uses the standard stacked layout: the media sits on top with descriptive text placed directly underneath it.
- **Portrait Media (9:16 / vertical story/reel videos & posters):**
  - **Desktop / Tablet (width > 680px):** Automatically switches to a spacious **Side-by-Side layout** (`max-width: 860px`).
  - **Mirrored Directionality:**
    - **LTR (English & German):** Media sits on the **left**, descriptive text on the **right**.
    - **RTL (Persian):** Media sits on the **right**, descriptive text on the **left** for a natural reading flow.
  - **Mobile Screens (width <= 680px):** Gracefully stacks with a proportioned vertical viewport (`44vh`) to ensure the modal never overflows smaller smartphone screens.
  - **Dedicated Mobile Pagination Bar:** On mobile screens, the slide pagination indicators are anchored in their own dedicated footer bar below the scrollable text area. This eliminates any overlap with headings, event details, or contact buttons and guarantees smooth vertical scrolling across all viewport sizes.
- **Uncropped Display:** Uses `object-fit: contain` with an ambient dark backdrop to guarantee that no poster dates, logos, or video details are ever cropped.
